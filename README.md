# ReviveAI

## AI-Powered Revenue Recovery

ReviveAI is a simple revenue-recovery demo that helps identify abandoned shopping carts and estimate their recovery potential.

## Problem

E-commerce businesses lose revenue when customers abandon their shopping carts. ReviveAI provides a simple way to identify lost cart value and estimate the possibility of recovering that revenue.

## Features

- Displays abandoned customers
- Calculates total lost revenue
- Predicts recovery probability
- Interactive web dashboard
- Flask backend
- HTML/CSS/JavaScript frontend

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

## How to Run

1. Install Python.
2. Install Flask:

   pip install Flask

3. Run the application:

   python app.py

4. Open:

   http://127.0.0.1:5000
